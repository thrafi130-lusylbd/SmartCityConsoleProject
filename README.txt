ECLIPSE IMPORT
1. Extract the ZIP file.
2. Open Eclipse > File > Import.
3. Choose General > Existing Projects into Workspace.
4. Select the extracted SmartCityConsoleProject folder as root directory.
5. Click Finish. Open src/main/Main.java and Run.

PACKAGES
main - menu, base abstract class, custom exception
energy - energy management
farming - irrigation and custom exception
waste - waste types, ArrayList and polymorphism
weather - weather sensor threads
drone - drone inheritance and multithreading
home - interface, abstract class, anonymous object, encapsulation
emergency - emergency types and threaded response

Console only: no database and no GUI. Thread output order may vary.
